# URL migration map

The site moved from `caseykeown.com` (flat `.html` files) to `twinlakesweb.com`
(directory URLs). `caseykeown.com` is retained for email at `me@caseykeown.com`.

## Same-site redirects (already implemented)

GitHub Pages cannot issue server-side 301 responses. Every old path below keeps a
small HTML stub at its original location, generated by `scripts/build_site.py`.
Each stub carries `rel="canonical"` to the new URL, `noindex, follow`, a meta
refresh, and a JavaScript replace that preserves the query string and fragment.
Search engines treat that combination as a redirect and pass ranking signals to
the canonical target.

| Old path | New path |
|---|---|
| `/about.html` | `/about/` |
| `/services.html` | `/services/` |
| `/work.html` | `/work/` |
| `/projects.html` | `/work/` |
| `/portfolio.html` | `/work/` |
| `/leads.html` | `/contact/` |
| `/contact.html` | `/contact/` |

GitHub Pages already serves `/about` as `/about/`, so the extensionless forms
need no stub of their own.

Blog URLs did not change shape and need no redirects:

- `/blog/` stays `/blog/`
- `/blog/articles/<slug>/` stays `/blog/articles/<slug>/`
- `/blog/feed.xml` stays `/blog/feed.xml`

`/blog/sitemap.xml` was a stale duplicate and was removed. The live sitemap is
`/sitemap.xml`, generated by `scripts/build_blog.py`.

## Cross-domain redirects (needs Casey to configure)

Requests to `caseykeown.com` must be redirected to `twinlakesweb.com` at the DNS
or hosting layer, because this repository now serves `twinlakesweb.com` only.
The mapping is one to one:

| Old URL | New URL |
|---|---|
| `https://caseykeown.com/` | `https://twinlakesweb.com/` |
| `https://caseykeown.com/about.html` | `https://twinlakesweb.com/about/` |
| `https://caseykeown.com/services.html` | `https://twinlakesweb.com/services/` |
| `https://caseykeown.com/work.html` | `https://twinlakesweb.com/work/` |
| `https://caseykeown.com/leads.html` | `https://twinlakesweb.com/contact/` |
| `https://caseykeown.com/blog/` | `https://twinlakesweb.com/blog/` |
| `https://caseykeown.com/blog/articles/<slug>/` | `https://twinlakesweb.com/blog/articles/<slug>/` |
| anything else | `https://twinlakesweb.com/` |

Options, in order of preference:

1. **Cloudflare (recommended).** Keep `caseykeown.com` on Cloudflare DNS, add a
   Bulk Redirect or a Redirect Rule: match `caseykeown.com/*` and redirect to
   `https://twinlakesweb.com/${1}` with status 301, preserving the query string.
   Add the four `.html` to directory pairs above as explicit rules so old links
   land on the right page instead of the homepage.
2. **A second GitHub Pages repository.** Publish a small repo containing a
   `CNAME` of `caseykeown.com` and the same canonical redirect stubs used here.
3. **Netlify or Cloudflare Pages.** The `_redirects` file in this repository is
   already written in that format and can be reused on the old domain.

Keep the cross-domain redirects in place permanently. Do not remove the old
domain's DNS while `me@caseykeown.com` is the contact address in use.
